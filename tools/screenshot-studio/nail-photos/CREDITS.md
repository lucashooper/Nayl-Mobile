# Nail Progress photos (Frame 5)

Put the four photos for the Nail Progress frame here, named by day:

- `day-1.jpg`: slightly bitten, uneven nails (starting point)
- `day-5.jpg`: cleaner cuticles starting to grow back
- `day-9.jpg`: well-kept, smooth natural nails
- `day-14.jpg`: healthy, fully restored, polished nails

`.png` and `.webp` work too. The studio picks them up on reload; each tile can also be
set from the "Nail Progress photos" section in the sidebar.

Only use photos you own or that are licensed for commercial use (for example under the
